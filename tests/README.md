# tests

Cross-cutting test suites for AEGIS.

- `contract/` — schema, layout, and boundary contract tests
- `integration/` — PostgreSQL, Redis, and object-storage integration tests (later phases)
- `e2e/` — Playwright end-to-end tests (later phases)
- `performance/` — performance benchmarks (later phases)
- `golden-replays/` — deterministic replay golden artifacts (later phases)
