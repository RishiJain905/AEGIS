# AEGIS v1.0.0 Release Notes

## Release identity

- Version: `1.0.0` / tag name `v1.0.0`
- Source: the release manifest records the exact source revision at generation time;
  the orchestrator's later local commit and tag will supersede that revision.
- Scope: local, simulation-only release preparation. No cloud deployment, registry
  push, or publication was executed, per [ADR 0033](../AEGIS-v1.0-Agent-Specs/adrs/0033-deployment-readiness-without-executed-deployment.md).

## Evidence-backed contents

Phase 34's full validation manifest reports a passed offline gate, integration suite,
golden replays, security suite, failure-injection suite, deployment smoke, performance
stage, and five Chromium E2E journeys: [release-20260718T180513Z-bdc9fadb.json](evidence/release-20260718T180513Z-bdc9fadb.json).
The later local rerun also reports all seven required validation stages passed:
[release-20260718T184549Z-bdc9fadb.json](evidence/release-20260718T184549Z-bdc9fadb.json).
The coverage and command-to-evidence mapping are defined in the [release test plan](test-plan.md)
and [Phase 34 handoff](../handoffs/34-full-system-validation-HANDOFF.md).

The release includes the API/web shell, declarative scenario SDK, deterministic
simulation, live graph and telemetry views, detection/ML evidence, mock and recorded
model-provider modes, agent proposals, approvals, replay, cinematic view, scoring, and
after-action review. These are simulation workflows over synthetic or local data; they
are not production control-plane integrations.

## Known limitations

The [known-issues register](known-issues.md) remains part of the release record:

- The web image has 23 open fixable HIGH transitive findings requiring dependency-owner
  remediation or a finding-specific approved exception.
- 3D first render is currently approximately 4-8 seconds and is measured each release.
- Windows `pnpm build` can fail with symlink `EPERM` under local file-lock conditions.
- Live and local provider modes have graceful-degradation coverage but were not run with
  real credentials or endpoints.

These are disclosed limitations, not silent waivers.
