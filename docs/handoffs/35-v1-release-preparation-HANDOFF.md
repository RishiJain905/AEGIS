## Documentation verification

The clean-machine walkthrough uses a fresh local clone with the pending working-tree
patch overlaid because the implementation is intentionally uncommitted. It follows
`docs/getting-started.md` through environment bootstrap, frozen pnpm/uv installs, and
the offline verification gate. Any gap found during that walkthrough must be recorded
in the final Phase 35 report and corrected before the release is accepted.

## Known limitations carried forward

- Web image: 23 open fixable HIGH transitive findings; remediation or a finding-specific
  approved exception is required before publication.
- 3D first render baseline: approximately 4-8 seconds.
- Windows local `pnpm build` can fail with symlink `EPERM` under file-lock conditions.
- Live/local provider modes have graceful-degradation coverage only; no real endpoint or
  credentials are part of this local release preparation.
- Firefox and WebKit E2E were skipped because their Playwright executables were not
  installed in the validation environment.
